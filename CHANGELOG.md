# Changelog

## 0.1.0 — Initial implementation

- Added phase 0 reference analysis and architecture documents.
- Added shared Swift measurement core with monotonic sessions, marks, process CPU sampling, physical-footprint sampling, CADisplayLink cadence estimates, thermal/application state, signposts, JSON/CSV output, and active-session-only sampling.
- Added thin React Native and Capacitor bridges and TypeScript contracts.
- Added a local external-project registry, Xcode build/XCTest runner, xcresult attachment collection, and SDK-result comparison summaries.
- Added an external-repository Performance Skill and installation/measurement documentation.

This is an initial implementation. Native adapter integration and end-to-end benchmark comparison still need validation in real host applications.
